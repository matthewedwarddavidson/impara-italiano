# Decisions

- **Copy Deutsch lernen, don't share a core (2026-11-10).** The German app's types and marking are German-specific (articles, cases, separable verbs). Copying the shell and rewriting the language layer is faster than extracting a shared library for two apps. Revisit if a third language comes along.
- **No spending.** Free hosting (GitHub Pages), free tools, open-source voices.
