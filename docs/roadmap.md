# Roadmap

Each stage is a GitHub milestone; each piece of work is an issue in it. Points size an issue by implementation effort: 1 tweak, 2 small feature, 3 feature across pages, 5 system needing a short design, 8 big piece over several sessions, 13 break down before starting.

| Stage | Goal |
|---|---|
| 0. Foundations | Agree level and goals; app shell from Deutsch lernen with Italian types; deployed to GitHub Pages |
| 1. Core loop | Usable every day: A1 words, learn and review, Italian-aware marking, Today and Progress, sync |
| 2. Grammar A1–A2 | Grammar topics with tables and exercises; verb conjugation drills |
| 3. Reading and listening | Graded texts and dialogues A1–A2, dictation |
| 4. Recorded audio | Natural Italian voices for all built-in content |
| 5. Writing and exams | Writing tasks with model answers; practice for her chosen exam |
| 6. B1 and beyond | Words, grammar and texts up to B1 |
| 7. Bridges and polish | English–Italian bridge, phone polish, content accuracy checks |
